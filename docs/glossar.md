# Humplore Glossar

Stand: 12. August 2026

| Begriff | Verbindliche Bedeutung |
|---|---|
| Nutzer | Registrierter Account, der Inhalte entdecken, fragen, kommentieren, melden und speichern kann. |
| Creator | Nutzer, der unter einem frei gewählten, auch fiktiven Nutzernamen für ein bestimmtes Thema eigene Erfahrungen veröffentlicht; eine Verifizierung ist dafür nicht erforderlich. |
| Thema | Konkreter Erfahrungsbereich eines Creators, zum Beispiel `ADHS`. |
| Themenkategorie | Breite Gruppe konkreter Themen, zum Beispiel `Krankheit`. |
| Beitragskategorie | Lebens- oder Inhaltskontext eines Beitrags, zum Beispiel `Alltag`; unabhängig von Thema und Themenkategorie. |
| Beitrag | Von einem Creator veröffentlichter Text-, Bild- oder Videoinhalt. |
| Frage | An einen Creator gerichteter Inhalt, der direkt oder als Beitrag beantwortet werden kann. |
| Kommentar | Öffentliche Reaktion unter einem Beitrag. |
| Anonyme Frage | Frage ohne sichtbare Zuordnung zum fragenden Account; die interne Betreiberzuordnung bleibt erhalten. Andere Inhaltstypen werden nicht anonym veröffentlicht. |
| Verifizierung | Optionales, themenbezogenes Vertrauenssignal nach Betreiberprüfung; es ist keine Veröffentlichungsvoraussetzung und kann die Ausspielung von Beiträgen positiv gewichten. |
| Meldung | Nicht öffentliche Bitte an die Betreiber, einen Beitrag, eine Frage oder einen Kommentar zu prüfen. |
| Moderationsfall | Meldung samt Status, Entscheidung und späterem Audit-Trail. |
| `Neues gelernt!` | Öffentliche Lernreaktion auf einen Beitrag; technisch aus der bisherigen Like-Logik hervorgegangen. |
| Merken | Private Zuordnung eines Beitrags zum aktuellen Nutzer ohne öffentlichen Zähler. |
| Explore | Zentrale Discovery-Ansicht mit Suche, Filtern, Übersicht und Feed. |

Neue Fachbegriffe werden hier definiert, bevor verschiedene Dokumente oder
Oberflächen unterschiedliche Bezeichnungen verwenden.
