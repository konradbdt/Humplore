# SpecKit-Archivhinweis

SpecKit wird seit dem 24. Juli 2026 nicht mehr parallel zu OpenSpec als aktive
Aufgaben- und Statusquelle gepflegt. Die früheren Features wurden unverändert
nach `docs/archive/spec-kit/` verschoben.

Neue Anforderungen, Designs und Tasks werden ausschließlich unter `openspec/`
geführt. Dadurch entstehen keine doppelten Checklisten oder voneinander
abweichenden Statusangaben.
